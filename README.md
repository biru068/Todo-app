# 📝 React To-Do App

A simple and responsive To-Do application built with **React.js**. This project helps users manage daily tasks by adding, updating, completing, and deleting todos.

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Responsive design
- ⚡ Fast and user-friendly interface

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useState`)

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/biru068/react-todo-app.git
```

2. Navigate to the project folder

```bash
cd react-todo-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```

The application will run at:

```
http://localhost:5173
```

## 🎯 How to Use

- Enter a task in the input field.
- Click the **Add** button to create a new task.
- Click the checkbox to mark a task as completed.
- Click **Delete** to remove a task.
